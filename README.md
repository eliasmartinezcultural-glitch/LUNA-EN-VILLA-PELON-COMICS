# Luna en Villa Pelón — Cómic

## Versión 0.2 — motor de cómic

Esta versión conserva el lector funcional original y lo convierte en una base real de cómic digital.

### Lo que queda incorporado
- portada independiente;
- entrada clara a la historia;
- sistema de páginas separado de la interfaz;
- metadatos visuales por página para dirigir las futuras ilustraciones;
- continuidad de personajes, territorio y pistas preparada desde los datos;
- navegación con botones, teclado y gesto de deslizamiento en móvil;
- estado de página mediante hash para poder compartir una página concreta;
- fallback visual mientras todavía no existen las ilustraciones finales.

### Regla central

**Mucho sistema por detrás. Experiencia muy sencilla por delante.**

La ilustración definitiva no se improvisará página por página: cada imagen deberá respetar el canon visual de Luna, Abuelo, Villa Pelón, las bardas, el viento, los objetos y la continuidad espacial.

### Próxima capa

1. Biblia visual de personajes.
2. Biblia visual del territorio.
3. Sistema de continuidad de objetos y pistas.
4. Incorporación de ilustraciones finales por página.
5. Revisión de ritmo, composición y lectura móvil.
6. Congelación del motor cuando la lectura quede estable.

### Canon de esta versión

- Luna es protagonista activa, curiosa y observadora.
- El abuelo funciona como puente de memoria, no como autoridad absoluta.
- Villa Pelón es un personaje silencioso.
- Las pistas deben tener continuidad.
- La ficción y la historia documentada deben mantenerse diferenciadas.
