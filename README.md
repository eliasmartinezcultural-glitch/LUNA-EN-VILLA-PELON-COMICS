# Luna en Villa Pelón — Cómic

Primera base funcional del proyecto.

## Objetivo

Construir un cómic digital simple, móvil y multiplataforma, con una arquitectura preparada para crecer hacia ilustraciones reales, capítulos, archivo de personajes, pistas y capas históricas.

## Regla de arquitectura

Mucho sistema por detrás. Experiencia muy sencilla por delante.

## Estado

Versión 0.1 — lector funcional de 20 páginas con navegación por botones, teclado y controles de inicio/final.

## Próximas capas

- ilustraciones reales por página;
- portada;
- biblioteca de capítulos;
- canon y continuidad;
- modo lectura móvil;
- descargas;
- capa opcional "Detrás del cuento";
- pruebas de GitHub Pages.

No se agregan funciones innecesarias antes de validar el lector base.
