# Design System — Luna en Villa Pelón

## Dirección

Mucho sistema detrás. Muchísimo diseño delante. Muy poca fricción para leer.

## Jerarquía

1. Historia
2. Imagen
3. Contexto
4. Navegación
5. Información secundaria

## Tipografía

Cormorant Garamond: títulos y narrativa editorial.
Inter: navegación, etiquetas y metadatos.

## Paleta semántica

Noche = estructura digital.
Papel = lectura.
Tierra = territorio.
Arena = descubrimiento.
Cielo = atmósfera.
Tinta = texto.

## Responsive

Teléfono: una columna, controles táctiles grandes, lectura cómoda.
Tablet: página centrada y aire editorial.
Escritorio: experiencia amplia sin convertirse en una aplicación compleja.

## Accesibilidad

Controles textuales, contraste suficiente, teclado y reducción de movimiento.

## Regla editorial

Cada elemento debe ayudar a leer, entender o sentir la historia. Si no lo hace, no entra.

## Regla de producción

Las ilustraciones reales reemplazarán el arte provisional sin modificar el motor de lectura. El contenido, el motor y la interfaz permanecen desacoplados.
