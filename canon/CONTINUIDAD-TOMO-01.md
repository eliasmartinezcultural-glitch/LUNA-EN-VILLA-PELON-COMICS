# Continuidad Visual — Tomo 01: El secreto del viento

Este documento controla la continuidad de las 20 páginas.

## Estado inicial

### Páginas 1–3
- Luna está sola.
- Descubre huellas y objeto metálico.
- El territorio es protagonista.
- El misterio todavía es pequeño.

### Páginas 4–6
- Aparece el abuelo.
- Se establece la relación.
- El objeto pasa a ser una pista compartida.
- La memoria oral entra en la historia.

### Páginas 7–12
- Luna se desplaza hacia las bardas.
- El viento activa nuevas pistas.
- Aparece la página antigua.
- El símbolo se repite.
- Se incorpora el mapa.

### Páginas 13–16
- Aparece la caja.
- Las fotografías conectan pasado y presente.
- La comparación territorial se vuelve central.

### Páginas 17–20
- Luna regresa con el abuelo.
- El misterio cambia de “tesoro” a “memoria”.
- Luna crea su propio registro.
- El cierre vuelve al territorio.

## Regla de continuidad

Ningún elemento puede aparecer antes de su descubrimiento narrativo salvo que exista una razón visual deliberada.

El lector debe poder reconstruir la cadena:

**huella → objeto → abuelo → barda → página → símbolo → mapa → caja → fotografías → memoria.**
