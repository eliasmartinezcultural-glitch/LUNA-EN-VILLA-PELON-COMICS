# Preproducción Profesional — Tomo 01

## Estado de producción

**Proyecto:** Luna en Villa Pelón  
**Tomo:** El secreto del viento  
**Fase:** Preproducción visual  
**Objetivo:** fijar identidad, continuidad y storyboard antes de ilustrar.

### Regla

No producir ilustraciones finales hasta que los elementos maestros y el storyboard estén aprobados.

---

# Pipeline oficial

1. Canon narrativo
2. Biblia visual
3. Modelos maestros
4. Continuidad territorial
5. Storyboard
6. Diseño de página
7. Ilustración
8. Lettering
9. Control de continuidad
10. Integración digital
11. QA multiplataforma
12. Congelación de versión

---

# Puertas de aprobación

## Gate A — Universo

Debe estar definido:
- personajes;
- territorio;
- objetos;
- reglas;
- sistema de verdad.

## Gate B — Identidad visual

Debe estar definido:
- silueta;
- vestuario;
- lenguaje visual;
- luz;
- color;
- escala.

## Gate C — Narrativa visual

Debe estar definido:
- ritmo;
- planos;
- composición;
- pistas;
- transiciones.

## Gate D — Producción

Solo después:
- ilustraciones;
- lettering;
- montaje digital.

---

# Regla de cambio

Un cambio realizado después de una puerta de aprobación debe indicar qué elementos afecta.

Nunca corregir una contradicción creando otra.

---

# Ficha de aprobación de página

Cada página deberá evaluarse:

- [ ] narrativa clara
- [ ] composición clara
- [ ] personaje consistente
- [ ] territorio consistente
- [ ] objetos consistentes
- [ ] luz consistente
- [ ] dirección del viento consistente
- [ ] texto legible
- [ ] transición correcta
- [ ] aporta algo a la historia

Si una página falla en un elemento crítico, vuelve a revisión.
